# 🧪 Periodic Table

A simple and beginner-friendly Periodic Table of Elements built using **HTML and CSS only**. This project displays chemical elements in a structured layout inspired by the real periodic table.

## ✨ Features

- Complete Periodic Table layout
- Element symbols, atomic numbers, and names
- Different colors for element categories
- Clean and organized design
- Beginner-friendly code
- No JavaScript required

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
periodic_table/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the Periodic Table.

## 🎯 Project Purpose

This project was created to practice HTML and CSS fundamentals while building a visual representation of the Periodic Table.
